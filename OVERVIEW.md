# alias

See which of your installed skills you use.

alias reads the usage log Claude Code keeps on your machine and counts how many times each skill ran. The screen shows:

- how many of your installed skills you have used
- your most used skills, with counts
- the skills you installed and never used
- skill links that point to a missing folder, with a command that fixes each one

Open it from the sidebar or from the Command Center under "Skill usage".

## Sharing

Sharing is off until you turn it on. When you share, alias publishes your skill names and use counts to a public page on alias.computer and gives you the link. The contents of your skills, their descriptions and your file paths stay on your machine. You can stop sharing from the same screen.

Shared profiles feed a public table at alias.computer/skills. For each skill it shows how many people installed it, how many used it and the total number of uses.

You can add your X handle to a shared profile. The page then shows your X name and picture. To prove the account is yours, put your profile link in your X bio; alias checks for it and marks the profile verified.

## Limits

Use counts cover Claude Code, Codex and Gemini CLI. Claude Code counts each time a skill runs. Codex and Gemini are counted once for each session that opened the skill. Cursor keeps no usage log, so its skills are listed as installed and are not counted.
